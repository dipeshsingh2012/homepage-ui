# Homepage UI Fragment (`homepage-ui`)

> **Micro-Frontend (MFE) Landing Page Fragment powered by Contentful GraphQL (`homepage-service`)**

`homepage-ui` is a standalone, embeddable frontend fragment providing the landing page experience. It features:
- **Spatial Hero Qualifier:** Dynamic banner allowing shoppers to qualify appliances by kitchen clearance.
- **Category Navigation Cards:** Links to curated appliance segments.
- **"How It Works" Spatial Storytelling:** Visual explanation of camera-based clearance estimation.
- **Bestsellers Showcase:** Highlighting top-rated kitchen appliances.

---

## 🚀 Tech Stack

- **Framework:** React 18 / TypeScript 5 / Vite 5
- **Styling:** Tailwind CSS
- **Backend Service:** `homepage-service` (Port 8002)

---

## 💻 Development

```bash
npm install
npm run dev     # Runs dev server on port 5174
npm run build   # Compiles standalone MFE bundle
```
